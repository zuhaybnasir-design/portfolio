Airport Concurrency Simulation.

A console-based Java airport simulation coordinating six aircraft, a single runway, three gates and one shared refuelling truck through explicit thread synchronization.

PROJECT OVERVIEW

Coordinating shared airport resources.

Six plane threads progress through landing requests, runway use, docking, passenger disembarkation, ground-crew cleaning and refuelling, passenger boarding, and eventual take-off. Arrivals are spaced by zero to two seconds, and the simulation limits airport ground occupancy to three aircraft.

An Air Traffic Control (ATC) thread manages landing and take-off requests and reserves the runway and gates. A dedicated refuelling-truck thread processes requests from multiple planes.

MULTITHREADING & LOCKING

Explicit concurrency primitives.

The Java classes extend Thread and coordinate with synchronized, wait() and notifyAll(). ATC manages separate emergency landing, normal landing and take-off queues, protects runway and gate state, and signals waiting requests when a resource becomes available.

Independent passenger and ground-crew threads allow tasks to overlap, while a single refuelling worker ensures only one aircraft is serviced by the truck at a time.

EMERGENCY SCENARIO

Prioritizing a fuel-shortage aircraft.

Plane-6 is configured to request an emergency landing. The ATC scheduling logic checks emergency requests before normal arrivals when it can safely assign a runway and gate. The refuelling worker also checks its urgent queue before queued normal requests.

Priority remains conditional on shared resource availability; this is a classroom simulation rather than a real air-traffic safety system.

OBSERVABILITY

What the example output shows.

The repository contains a sample console log where six aircraft complete their tasks, every gate is empty at the end, and the summary reports 276 passengers boarded. The report also prints minimum, average and maximum waiting times.

These are sample-run results: operating-system scheduling and thread interleaving can change their ordering and elapsed timings. The included presentation outline describes how to demonstrate the key shared resources and emergency-priority scenario.

ENGINEERING EVIDENCE

Source code and limitations.

The Eclipse project contains ATC.java, Plane.java, RefuelTruck.java, passenger and ground-crew worker classes, request-signalling objects, and a synchronized statistics collector. The code demonstrates important concurrency ideas but has not been independently stress-tested here.

The included repository notes describe CT074-3-2 Concurrent Programming coursework. No full final report or verified individual-contribution record was included in this upload, so specific authorship is not asserted.

Learning Assistant in C.

A console-based educational assistant that manages learner records, suggests study resources using rules, logs learning activities and produces progress summaries.

OVERVIEW

Keeping learner records organised.

The program is divided into C source and header modules for learner management, content loading, recommendations and utility functions. Its main menu supports adding and updating learners, removing profiles, viewing records, recording activities, recommending resources, viewing progress and attempting exercises.

Local text files store learner profiles and learning resources. Activity logs record a learner, an action and a timestamp for later feedback analysis.

RECOMMENDATION LOGIC

Personalisation through simple rules.

The current recommender compares a learner's preferred resource type and skill level with content type and difficulty. Matching resources are shown and can be logged as recommendations. This is a rule-based feature, not a trained recommendation model.

The difficulty comparison deserves further validation, since the current condition may recommend items that are harder than the learner's level.

INTERACTION & FEEDBACK

Exercises and progress reports.

  • Read a list of available exercises from the local content dataset.
  • Record pass/fail exercise attempts and log the action.
  • Display preset feedback based on recorded failed attempts.
  • Generate a learner report with recorded skill level, preferred content type and progress score.
IMPLEMENTATION

How it's structured.

The repository includes main.c, learner.c, content.c, recommender.c, utils.c and matching header files. It uses C structures, fixed-size arrays, file I/O, strings, conditionals and loops.

HONEST SCOPE

Prototype limitations.

Source inspection suggests improvements around input validation, file capacity checks, portable case-insensitive string handling and unique learner IDs. The program has no authentication or production privacy controls. No external machine-learning service is used.

The code has been reviewed at source level for this portfolio description, but has not been independently compiled or functionally tested. The source repository remains private while its existing interaction logs are reviewed.
